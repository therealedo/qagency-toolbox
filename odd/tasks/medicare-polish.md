## Specs

S1. User: "Rename the main tab to [MC] Medicare Advantage". The line chip keeps its MC badge and reads "Medicare Advantage".

S2. App enviada. User: "Medicaid is being written like this on the note: "Medicaid: SI - ID 12345678". Keep it simple, just "Medicaid ID: 12345678""

S3. App enviada. User: "Make Fecha del SOA to be the same date the note is being generated by default". It follows the note date until edited or filled by an SOA PDF.

S4. App enviada. User: "Eliminate Contrato (H-PBP). It goes into the name of the plan". The PDF reader appends the contract to the plan name when the name doesn't already have it.

S5. App enviada. User: "Make Prima mensual a toggle as most plan dont cost anything". Assumption: toggle off (default) writes "Premium: $0.00"; on shows the amount field. A PDF with a premium above $0 turns it on.

S6. App enviada. User: "Eliminate the Pendiente y proximo paso Section"

S7. App enviada. User: "Agente y Colaborador: In this case there's no collaborator. The one who is selected as Soy on the top right (the one writing the note) is the one doing the application and should be be default the one who spoke with the client (this is already like that)"

S8. App enviada. User: "App Summary is going to be only App instead" (Network label; file name unchanged).

S9. App enviada. User: "SMS format leave it like that but add it to your engram memories is pending to update once i get our standard format tomorrow" (saved as qagency/medicare-sms-format-pending) and "No email section here".

S10. User: "Add an Etiqueta final of CRONIC and make these dropdown to be a multi select field (attachin one after the other like CRONIC URGENT)". Applies to the task box on every line; CRONIC also joins the Tasks tab tags.

S11. App enviada. User: "No. de confirmacion from the Plan section should be App ID instead". Note label becomes "App ID".

S12. User: "Eliminate: SOA Pendiente (should be implicit on the App enviada tab), Cita AEP, Sin contacto, Interesado, No interesado and Cancelacion tabs." The SOA Firmado/Pendiente switch goes too; App enviada assumes a signed SOA.

S13. Sin cambios. User: "Leave Sin cambios but make the note format like this:"
```
ER_11/14/2026: Se atiende al cliente en cita telefónica (09:00), se revisan los beneficios de su plan para 2027 y decide mantenerse en su plan actual - [NAME OF THE PLAN]
```
"Eliminate MBI, ID de Medicaid, Part A and B fields. We dont need them." / "On the plan section keep: Name of the plan only" / "Eliminate Pendiente y proximo paso section" / "Network: we only need to check up the SOA" / "You can add a toggle on the Cliente section called Es cliente. If toggled off, the automatic task would be FOLLOW UP LEAD_INACTIVE CLIENT MC" / "In reporte para cliq you are going to add the following text format filled up: "[LAST NAME, FIRST NAME] se quedara en su mismo plan [PLAN NAME]" (We also have another channel called NO CHANGE to paste this text when someone desides to stay on the same plan)" / "No SMS section here".
Assumptions: no Gestión section in Sin cambios (the SOA file date uses the note date); the note is the header line plus the Network line; names as in the other reports ("Diaz, Beatriz").

S14. User: "Also generally delete for all the application the Sin acentos checkbox under messages" (the SMS checkbox; the note option in Ajustes stays).
